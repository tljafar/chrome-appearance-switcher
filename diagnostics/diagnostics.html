Native Host Installation Guide

1

Download the Native Companion ZIP

Download the official lightweight Windows companion package for your operating system:

Download native-companion-installer.zip
2

Extract ZIP & Run Installer

Right-click the downloaded ZIP file, select Extract All, open the extracted folder, and double-click install_host.bat.

What it does: Registers com.appearance.switcher under HKCU\Software\Google\Chrome\NativeMessagingHosts pointing to host_launcher.bat.
3

Set Chrome to "Device" Theme

Navigate to chrome://settings/appearance and select Device so Chrome reflects Windows appearance changes in real time.

4

Verify Connection

Return to this Diagnostics page and click [ Run Test ]. All 6 subsystems will show green checkmarks (✓).
